# Simple Banking System

A Python-based console application created as a practice project to strengthen programming logic, problem-solving skills, and Python fundamentals.

## Features

- Create bank accounts
- View account details
- Deposit money
- Withdraw money
- Check account balance
- Search for an account
- View all accounts
- Basic input validation

## Concepts Practiced

- Lists and dictionaries
- Loops and conditions
- Functions
- User input
- Searching and updating data
- Basic validation
- Program flow and logic

## Purpose

This project is part of my ongoing journey to build a strong foundation in **Python programming and problem-solving skills**.
