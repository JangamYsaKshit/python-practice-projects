# Inventory Management System

A console-based **Inventory Management System built with Python** for managing products, stock levels, sales, restocking, and inventory statistics.

## Features

* Add and manage products
* View complete inventory
* Search products by Product ID
* Update product information
* Remove products
* Sell products and update stock
* Restock products
* Calculate inventory statistics
* Track total inventory value
* Identify the most expensive and lowest-stock products

## Tech Stack

* **Python 3**
* Lists & Nested Lists
* Functions
* Loops
* Conditional Statements
* List Indexing & Methods

## Data Structure

Products are stored using a **list of lists**:

```text
[Product_ID, Product_Name, Category, Price, Quantity]
```
