# Student Grade Manager

## Overview

Student Grade Manager is a Python-based console application designed to manage and analyze student grades.

The application allows users to add student names and marks, view their grades, calculate the average marks, and identify the highest and lowest performing students.

This project was built as part of my Python learning journey to strengthen my understanding of dictionaries, loops, conditional logic, and basic data processing.

## Features

- Add student names and marks
- Store student information using a dictionary
- Display student marks along with their corresponding grades
- Calculate the average marks of all students
- Display the total number of students
- Identify the student(s) with the highest marks
- Identify the student(s) with the lowest marks
- Prevent the program from crashing due to basic menu errors
- Provide a simple menu-driven console interface

## Grading System

The application assigns grades based on the student's marks:

| Marks | Grade |
|------:|:-----:|
| 90–100 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| Below 50 | Fail |
