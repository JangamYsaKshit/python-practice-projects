# To-Do List Manager Hello

A beginner-friendly Python console application that allows users to create and manage a list of tasks. This project uses Python lists to store active and completed tasks.

## 📌 Project Overview

The To-Do List Manager allows users to:

- Add new tasks
- View active tasks
- Complete tasks
- Remove tasks
- View the total number of active tasks
- View completed tasks
- Exit the program

This project was created as part of my Python practice journey to improve programming logic, problem-solving skills, and understanding of Python lists.

## 🚀 Features

### Basic Features

- Add a new task
- Prevent duplicate tasks
- View all active tasks
- Mark a task as completed
- Move completed tasks to a separate list
- Remove tasks from the active task list
- View the total number of active tasks
- View completed tasks
- Handle invalid task names
- Handle invalid menu choices
- Exit the application
