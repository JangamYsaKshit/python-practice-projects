# E-Commerce Order Management System

A Python console-based project developed for practice purposes to improve my programming logic and problem-solving skills.

## Project Idea

The goal of this project is to build a simple system to manage products, customer orders, product quantities, and order totals. It includes basic operations such as adding products, searching products, creating orders, updating stock, and viewing sales summaries.

## Why I Chose This Project

I chose this project to practice real-world business logic and understand how different parts of an application work together. It helps me improve my understanding of Python functions, data structures, calculations, validation, and program flow.

## Concepts Practiced

- Python functions
- Lists and dictionaries
- Loops and conditions
- Searching and updating data
- Calculations and input validation
- Order and inventory management
- Problem-solving

## Purpose

This project is created **for practice and learning purposes only**. It is part of my journey to strengthen my Python fundamentals and build a foundation for future work in Data Science and Machine Learning.
