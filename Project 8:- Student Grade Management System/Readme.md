# Student Grade Management System

A simple Python console-based project created for **practice and learning purposes only**.

### Features
- Add student marks
- Display student records
- Update student marks
- Delete student records
- Calculate student statistics
- Grade classification
- Sort marks (Ascending & Descending)

### Technologies Used
- Python
- Lists (In-Memory Storage)

### How to Run
```bash
python main.py
```

### Note
This project was created for practice and learning purposes only. Student data is stored temporarily in a Python list and is not permanently saved.
